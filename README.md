# Portafolio Personal

Este proyecto es un portafolio personal realizado con PHP y MySQL.  
Contiene una página de inicio con información personal, un formulario de contacto y un panel de administrador para revisar los mensajes enviados.

## Herramientas usadas

- HTML
- CSS
- Bootstrap
- PHP
- MySQL
- phpMyAdmin

## Funciones del proyecto

- Muestra información personal del estudiante.
- Tiene una sección de hobbies e intereses.
- Permite enviar mensajes desde un formulario de contacto.
- Guarda los mensajes en una base de datos.
- Tiene un login para el administrador.
- Permite revisar los mensajes desde un panel privado.

## Uso del proyecto

1. Copiar la carpeta `portafolio_php` dentro de `htdocs`.
2. Encender Apache y MySQL en XAMPP.
3. Crear la base de datos `catalogo_productos_db`.
4. Importar el archivo `database.sql`.
5. Ejecutar una sola vez `crear_admin.php` para crear el usuario administrador.
6. Abrir el proyecto en el navegador:

http://localhost/portafolio_php/
